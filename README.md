# Multi-Factor Authentication (MFA) Security Research

## Overview

Research on Multi-Factor Authentication (MFA), common authentication vulnerabilities, and techniques used to bypass MFA.

## Topics Covered

- MFA fundamentals
- Email security
- MFA-related attacks
- MFA fatigue
- SIM swapping
- Adversary-in-the-Middle (AiTM) phishing
- Email-based MFA
- Account recovery weaknesses
- FIDO2 / WebAuthn
- Passkeys
- MFA security testing

## Objective

To understand how MFA improves account security, identify common weaknesses in MFA implementations, and explore security practices that can strengthen authentication.
